What this tool is for

Suivi Relance Scan — Collab brings together the JSON exports from everyone's individual tool into one shared view, so the whole team can see combined follow-up and scan stats without a shared file or a server.

Privacy

Everything you upload goes straight from your browser to the shared Google Drive folder, using your own Google account. This page has no server and no database of its own — it only reads and writes files in that Drive folder, with your account's own permissions.

How it works

  1. Sign in with your Google account (step 1).
  2. In your individual desktop tool, export your history as JSON, then drop that file here to contribute it (step 2).
  3. The Overview tab (step 3) shows combined totals and a breakdown per contributor, plus the list of imported files.
  4. The Trends tab turns the combined data into the same analysis as the individual tool: daily scan rate, breakdown by commitment level, doctor scorecard, Scan rookie/NSPTM leaderboard, and Aircall call outcomes — all computed across the whole team, with an optional filter by campaign type (Calls/Email/SMS).
  5. A file can only be imported once — uploading the same export again is blocked automatically to avoid duplicates.
  6. Everyone can delete their own imports; the tool administrator can delete any import.
